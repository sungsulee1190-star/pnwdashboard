# 인쇄용지 시장 및 경쟁사 분석 대시보드

중국·한국 수출 통계, 가격, 생산설비 지도와 14개 경쟁사의 사업 구조·제품·보고 실적·채무·공식 전망·뉴스를 확인하는 정적 대시보드입니다.

## 실행

Python 3에서 저장소 루트에 `python3 -m http.server 8000`를 실행하고 `http://localhost:8000`을 여세요. 뉴스 JSON을 읽기 위해 HTTP 서버를 권장합니다. 별도 프레임워크 빌드나 API 키는 필요하지 않습니다. Chart.js, Leaflet 및 스타일 CDN은 인터넷 연결을 사용합니다.

## 정보 읽기

- 수출 통계는 선택한 월·지역·국가·수출사에 따라 집계됩니다. 동기 비교는 확보된 동일 월을 비교하며 비교 자료가 없으면 산출 불가로 표시합니다.
- 경쟁사 분석의 매출·손익·채무는 기간, 통화, 단위, 법인/사업 범위 및 지표 정의와 함께 읽으세요. 서로 다른 기간·통화·범위의 숫자를 자동 순위로 만들지 않습니다.
- 전망은 회사 발표 전망이며 자체 예측이 아닙니다. 공개 자료에서 확인하지 못한 판매량·점유율·채무는 미공개/확인 필요로 표시합니다.
- 공식 자료 확인일, 뉴스 발행일과 자동 수집 성공일은 서로 다릅니다. 수집 실패 시 마지막 자료를 유지하며 실패 상태를 보여 줍니다.

## 자료와 갱신

`data.js`는 기존 수출·가격·설비 자료입니다. 이번 작업은 원본 통계 수치를 변경하지 않습니다. 경쟁사 조사 원본은 `research/asia.json`, `research/global.json`이며 공식 출처 링크와 개별 지표의 근거를 포함합니다. 자료를 수정한 뒤 `npm run build:research`로 `intelligence_data.js`를 생성합니다.

`intelligence/news.json`은 검토한 초기 뉴스와 수집 뉴스입니다. `intelligence/update-log.json`은 공식 소스별 성공·실패·수동 확인 상태입니다. 수집기는 날짜와 링크를 검증하고 기존 자료를 보존합니다. 정기 작업은 main에 워크플로가 반영된 뒤 매일 **06:00 UTC(한국 15:00)** 실행되며 변경 사항을 검토용 PR로 제안합니다. 자동 병합이나 배포는 하지 않습니다. 재무·사업 구조 자료는 공식 공시를 검토한 뒤 별도로 갱신합니다. 자세한 절차와 수동 확인 대상은 [docs/UPDATES.md](docs/UPDATES.md)를 보세요.

ChatGPT에는 14개 경쟁사의 공식 뉴스·공시·재무 변화를 매일 확인하는 별도 조사 작업을 등록했습니다. 의미 있는 새 내용이 있을 때 한국어 조사 결과와 갱신안을 전달하며, 저장소 코드나 배포를 직접 변경하지 않습니다. 이 조사 작업과 저장소의 뉴스 수집 워크플로는 별개입니다.

## 검증

Node 24+, Python 3.10+에서 실행합니다. 테스트는 추가 패키지 설치 없이 동작합니다.

```sh
npm test
python3 tests/update-pipeline.test.py
node research/build.cjs
node --check data.js
node --check dashboard_logic.js
node --check competitor_intelligence.js
node --check intelligence_data.js
```

회귀 테스트는 기간/필터·메일/결측·지역 비중·지도 집계·출처 안전성·정보 신선도·뉴스 파서·수집 실패 보존·조사 자료 검증을 확인합니다.
