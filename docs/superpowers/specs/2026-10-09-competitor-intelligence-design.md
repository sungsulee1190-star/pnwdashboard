# 경쟁사 정보 및 대시보드 신뢰성 개선 설계

사용자 요청: 현재 오류를 수정하고 서브 에이전트를 사용하여 시장 조사, 경쟁사 사업 구조·재무/채무·제품·실적·판매 지표·전망 및 지속적인 뉴스 갱신을 구현한다.

## 사용자 목표
인쇄용지 시장의 경쟁사 상황을 한 곳에서 이해하고, 수치를 공식 출처에 대조하며, 새로운 뉴스와 공시가 있는지 확인할 수 있는 기존 대시보드를 만든다. 사용자 '채무 제품'은 채무·재무와 제품 분석, '판매율'은 공시된 판매 성장률/물량/가동률/점유율로 해석한다. 특정 우선순위 답변 전까지 기존 14개 제지사를 조사한다.

## 구조
기존 buildless HTML/JS를 유지한다. 원본 통계와 기업 목록은 data.js에 유지하고 출처 조사 자료는 research/asia.json, research/global.json에 독립 저장한다. 생성된 intelligence_data.js는 window.COMPETITOR_RESEARCH를 제공한다. competitor_intelligence.js/css가 기업·시장·뉴스 화면을 보강한다. Python stdlib 수집기는 검증한 공식 뉴스 소스를 수집하며 intelligence/news.json 및 update-log.json을 원자적으로 생성한다.

## 정확성 규칙
- 모든 재무 항목에 기간·통화·단위·집계 범위·출처를 보존한다. 연결/개별/사업부 및 조정/회계기준 이익을 혼합하지 않는다.
- 검증하지 못한 채무·판매량·점유율·예측은 null로 유지하고 화면에 미공개/확인 필요로 표시한다. 전망은 회사 발표 전망으로 표시한다.
- 뉴스 발행일과 수집 성공 시각을 분리하며 미래 발행일은 제외한다. 실패한 수집은 기존 자료를 보존한다.
- 수집 작업이 자동 작성한 설명과 실제 공식 발표를 혼동시키지 않는다. 공식 HTML 자료에서 발췌 불가하면 제목과 출처를 제공한다.
- 모든 표시 텍스트를 이스케이프하고 외부 링크는 HTTPS만 허용한다. 로컬 file:// 뉴스 링크는 사용 불가로 표시한다.
- 동기 비교는 동일 월 범위를 사용하고 필터를 분자·분모 모두에 적용한다. 데이터 부재는 0 실적으로 처리하지 않는다.

## 기존 오류 수정
데이터 문법, 이메일 탭 네비게이션·스키마·미포함 필터, KR 월/지역/국가 필터와 갱신, CN 정규화 지역 및 국가 필터·동기 비교·MoM·지역 비중, 이메일 국가별 합산, 지도 공장별 중복 및 허구 설비 사양, collapse 화살표를 수정한다.

## 갱신 및 인도
GitHub Actions는 매일 06:00 UTC 실행하고 변경분을 PR로 제안한다. main 자동 변경/자동 배포는 하지 않는다. 자료 수집 경로별 성공/실패/수동확인 상태를 표시한다. 재무자료는 검증한 공시 자료를 별도 갱신한다. 이번 작업도 기능 브랜치 및 초안 PR로 인도한다.

## 검증
Node 실제 로직/DOM harness 회귀 테스트, Python 수집기 parser/error-preservation 테스트, 모든 JavaScript 문법과 조사 JSON/출처/단위 검사를 실행한다. 가능한 환경에서 브라우저로 전체 사용자 흐름을 확인하고, 환경 제한 시 그 한계를 기록한다.
