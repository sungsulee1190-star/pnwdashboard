# 유럽 도공지 무역통계: 품목과 계산 근거

기준: 2026-11-13 확인. [Eurostat Comext DS-045409](https://ec.europa.eu/eurostat/databrowser/view/DS-045409__custom_6959191/default/table?lang=en) 2020.1~2026.8 보관 스냅샷. Eurostat는 수치를 소급 수정할 수 있다.

## 어떤 품목인가

| EU CN 8자리 | HS 6자리 | 내용 |
|---|---|---|
| 48101300 | 481013 | 롤 |
| 48101400 | 481014 | 펼친 상태로 한쪽 435mm 이하, 다른 쪽 297mm 이하의 시트 |
| 48101900 | 481019 | 기타(소형 규격을 넘는 시트) |

공통 조건은 필기·인쇄·그래픽용 종이 또는 판지, 무기물로 한 면 또는 양면 도공, 기계·화학기계 펄프 비중 전체 섬유의 10% 이하다. 도공 인쇄용지(CWF)의 통계상 근사 범위다. 한 면과 양면 도공을 구분할 수 없고, 회사·제품명·실제 공장·수출 물량의 원산지를 이 코드만으로 확인할 수 없다. 기계펄프가 10% 초과인 481022·481029와 비도공 백상지는 제외한다. [2026년 CN 관보](https://eur-lex.europa.eu/legal-content/EN/TXT/PDF/?uri=OJ%3AL_202501926), [오스트리아 통계청 2026 CN 영문표](https://www.statistik.at/fileadmin/pages/1135/WVZ_2026__CN2-_to_CN8-codes_with_description_EN.pdf), [EU 코드 설명](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=celex%3A52015PC0182).

## 수집과 계산

API는 `https://ec.europa.eu/eurostat/api/comext/dissemination/statistics/1.0/data/DS-045409`. 파라미터는 `freq=M`, `reporter=EU27_2020`, `flow=2`(수출), `product=48101300`, `48101400`, `48101900`을 각각 조회, `indicators=QUANTITY_IN_100KG`, 월별 `time`, 전체 `partner`다. 예: [2026년 1월 롤 조회](https://ec.europa.eu/eurostat/api/comext/dissemination/statistics/1.0/data/DS-045409?format=JSON&lang=en&freq=M&reporter=EU27_2020&flow=2&product=48101300&indicators=QUANTITY_IN_100KG&time=2026-01). 각 값은 100kg 단위이므로 10으로 나누면 톤이다.

2026-11-13에 [미국행 2026년 8월 48101300 표본](https://ec.europa.eu/eurostat/api/comext/dissemination/statistics/1.0/data/DS-045409?format=JSON&lang=en&freq=M&reporter=EU27_2020&partner=US&flow=2&product=48101300&indicators=QUANTITY_IN_100KG&time=2026-08)을 직접 조회했다. API 값 168,602.67은 100kg 단위로 16,860.267톤이며 보관 CSV와 일치했다. API의 갱신 표시는 2026-10-16이다. 이는 한 건의 표본 확인이며 전체 자료를 재다운로드한 것은 아니다.

수집 코드 `scripts/comext_eu_all_partners.py`, 변환 CSV `데이터_Comext/comext_eu27_all_partners.csv`, 지역 변환 코드 `scripts/eu_partner_map.py`, 역외 `eu27_by_country_month.json`, 역내 `eu27_intra_by_country_month.json`. CSV는 원 API 응답이 아니라 톤으로 변환한 스냅샷이다. JSON은 월·도착국별로 세 코드를 합치므로 JSON과 대시보드에서는 코드별 물량을 다시 분리할 수 없다. 코드별 계산은 반드시 CSV로 돌아간다.

### 새 CSV를 받았을 때

마켓맵 프로젝트 폴더에서 다음 두 명령으로 국가별 JSON과 각각의 `.metadata.json`을 함께 다시 만든다. 이 저장소의 월간 `update.bat`은 해당 JSON을 입력으로 DATA_MM을 다시 만들지만, CSV를 내려받거나 JSON으로 변환하지 않는다. CSV와 JSON이 다르면 빌드를 중단한다. 현재 스냅샷은 2026년 8월까지다.

```text
python scripts/eu_partner_map.py 스케치/마켓맵_보는화면_스케치.html 데이터_Comext/comext_eu27_all_partners.csv 데이터_Comext/eu27_by_country_month.json extra
python scripts/eu_partner_map.py 스케치/마켓맵_보는화면_스케치.html 데이터_Comext/comext_eu27_all_partners.csv 데이터_Comext/eu27_intra_by_country_month.json intra
```

국가별 JSON에 없는 선박 보급·미특정·공해는 메타데이터에 따로 기록한다. 기존 한솔 권역에 없는 목적지는 표의 기타에 포함하고 권역 확인 필요로 표시한다. 지도 이름이 경계 데이터에 없으면 지도에 점이 나타나지 않을 수 있다.

## 포함·제외와 읽는 법

집계코드는 국가별 합산에서 제외한다. 기존 변환에서 국가 매핑 전에 빠진 물량은 2020.1~2026.8 역내 슬로바키아 115,131.1톤(2026.1~8 8,177.4톤), 역외 합 47,230.1톤(그중 보스니아 30,310.3톤)이었다. 역외 미매핑에는 나라 외에 선박보급·미특정 등 특수코드도 있었다. 변환 수정 후 국가·지역은 보존하고, 특수코드는 사유와 월별 수량을 별도로 기록한다. `QV`는 역내 미특정으로 분류한다. 공식 집계행에는 일부 미특정 등이 포함될 수 있으므로 국가별 지도 값과 차이가 난다.

수정한 DATA_MM은 219개 도착지를 포함한다. 2026년 1~8월 유럽 도착지별 수치는 EU 역외 778,931.959톤, 역내 1,374,784.922톤이다. 이 값은 특수코드를 제외한 합계다. 기존 한솔 지역표에 없는 도착지는 기타에 포함하고 권역 확인이 필요하다.

역내 거래는 EU 회원국끼리 이동한 무역량이다. 동일 상품이 여러 번 거래되거나 이후 역외로 수출될 수 있다. 따라서 역내+역외를 더한 값은 고유 생산량이나 최종 수요가 아니다. EU 회원국 수출 신고는 기업별 판매나 제품 원산지와 같다고 단정할 수 없다.
