# 검토용 전달본

이 묶음은 pnwdashboard의 코드 수정과 경쟁사 조사 자료를 포함합니다. 기존 저장소에 적용할 때 원격의 `master_excels/` 자료는 유지하세요. 원본 엑셀은 이 묶음에 포함하지 않았습니다.

변경 사항은 기능 브랜치와 검토용 초안 PR로 제안합니다. 코드가 저장소 기본 브랜치에 반영되면 등록된 GitHub Actions 일일 뉴스 수집 워크플로가 활성화됩니다. Actions의 PR 생성 권한과 첫 실행 수집 결과는 확인이 필요합니다.

14개 경쟁사를 매일 조사하는 ChatGPT 작업은 별도로 등록 완료했습니다. 새 공식 뉴스·공시·재무 변화의 근거와 갱신안을 전달하며 저장소를 변경하지 않습니다.

실행 방법과 데이터 해석은 README.md, 수집기 설정과 실패 처리 방법은 docs/UPDATES.md를 참고하세요. 전체 회귀 검증 결과는 docs/VALIDATION.md에 기록합니다.
